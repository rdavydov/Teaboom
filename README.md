# Карточка товара Teaboom

Тестовое задание для HTML / Frontend-верстальщика: адаптивная верхняя часть карточки **«Ананасовый улун»** в стилистике Teaboom.ru. Реализация на HTML5, CSS и обычном JavaScript, без фреймворков, сборки и обязательных зависимостей.

- Репозиторий: [github.com/rdavydov/Teaboom](https://github.com/rdavydov/Teaboom)
- Адрес страницы в GitHub Pages: [rdavydov.github.io/Teaboom/](https://rdavydov.github.io/Teaboom/)
- Оригинальный товар: [teaboom.ru/product/ananasovij-ulun](https://teaboom.ru/product/ananasovij-ulun)

## Запуск

Можно открыть `index.html` непосредственно в браузере. Изображения и шрифты хранятся локально; для работы карточки внешние сервисы не нужны.

Для запуска через локальный сервер понадобятся Node.js и npm:

```sh
npm start
```

Откройте [http://localhost:4173/](http://localhost:4173/). Установка пакетов и отдельная сборка не требуются. Для остановки сервера нажмите `Ctrl+C`.

## Что реализовано

Изображение товара, название, категория, выбор фасовки, артикул, актуальная и старая цены, кнопка «В корзину» и короткое описание. При выборе фасовки сразу обновляются обе цены, артикул и выбранное состояние.

| Фасовка | Артикул | Старая цена | Актуальная цена |
| --- | --- | --- | --- |
| 100 г | 01306 | 349,20 ₽ | 326,40 ₽ |
| 500 г | 01307 | 1 646 ₽ | 1 432 ₽ |
| 1000 г | 01308 | 2 592 ₽ | 2 064 ₽ |
| 5000 г | 01309 | 8 710 ₽ | 6 320 ₽ |

Фасовки оформлены как группа радиокнопок и доступны с клавиатуры. Предусмотрены видимый фокус, состояния наведения и уведомление для скринридеров. Кнопка «В корзину» показывает демонстрационное подтверждение; backend и настоящая корзина не подключены.

Основные размеры для проверки адаптивности: **1440, 768 и 375 px**. На небольших экранах изображение и информация о товаре располагаются последовательно.

## Структура

```text
index.html                 — семантическая разметка
styles.css                 — оформление и адаптивность
script.js                  — переключение фасовок и демонстрация корзины
assets/                    — изображение, логотип и локальные шрифты
scripts/serve.mjs          — локальный статический сервер
tests/browser-checks.mjs   — сценарий браузерной проверки
package.json               — команды запуска и проверки
.nojekyll                  — публикация статических файлов в GitHub Pages
```

Проверка синтаксиса JavaScript:

```sh
npm run check
```

Браузерный сценарий в `tests/browser-checks.mjs` предназначен для проверки фасовок, взаимодействия с клавиатуры и адаптивности с помощью Playwright. Playwright не входит в обязательные зависимости страницы.

Для автоматической проверки установите только инструменты разработки:

```sh
npm ci
npx playwright install chromium
npm start
```

В другом терминале выполните `npm test`. Скриншоты и отчет сохраняются в `test-results/`. Проверяются все фасовки на 1440, 768 и 375 px, клавиатура, touch, наведение, отсутствие горизонтального скролла и ошибок. Для проверки опубликованной страницы задайте переменную `TEST_URL` с ее адресом перед запуском теста.

GitHub Pages использует ветку `main` и корень репозитория (`/`); публикуются исходные статические файлы.
